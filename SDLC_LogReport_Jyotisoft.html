📋 SDLC Methodology

This project followed the Waterfall SDLC model with iterative feedback loops. Each phase was reviewed and signed off by the supervisor before proceeding to the next phase. The 7-phase lifecycle included: Requirements Analysis → Low-Fidelity Design → High-Fidelity Design → Frontend Development → Admin Development → Backend Integration → Testing & Feedback → Final Delivery.
